# untitled-apk-assets

APK内に含まれているアセット等の管理リポジトリです。ダウンロード側のカタログには無い、アプリ本体側の素材を置きます。

- 取得元：公式アプリパッケージ（アプリ版7.1.0）から、UnityPy 1.25.4で取り出しました。
- 目録：`index.json` に配置した全ファイルのパス、SHA-256、サイズを記録します。
- 配信URLは `https://untitled-world.github.io/untitled-apk-assets/{path}` の形です。
- 変換が要るものは、原本と変換後の両方を置きます。

## 構成

| フォルダ | 件数 | 内容 |
|---|---|---|
| `sprite/` | 2807件 | 個別画像。アトラス（画像の束）ごとのサブフォルダに分け、束に入らないものは `standalone/` に置きます |
| `texture/` | 764件 | 画像そのもの。アトラスのページ画像を含みます |
| `font/` | 18件 | フォント本体とメタ情報（フォントごとにサブフォルダ） |
| `audio/` | 223件 | 組み込み音声。原本11件（.acb、.acf）と、再生できる形式（OGG）に変換した212件を、音声ごとのサブフォルダに並べて置きます。ループのある音声は2回繰り返し＋フェードアウトで変換しています |
| `app-res/` | 674件 | アプリ本体側の画像（Androidリソース） |

合計4486件、221643851バイトです。

テクスチャのうち12件は、パッケージ内に画像データを持たないプレースホルダ（実行時に生成されるフォントテクスチャ等）のため、配置していません。詳細は `index.json` の `noData` に記録しています。

アニメーションは配置対象に含めていません（定義の大半が圧縮された形式で保存されており、単独の素材として使いにくいため）。
